📦 API ENDPOINTS
─────────────────────────────────────────────────────────────────────────

USER ROUTES (/api/users)
  POST   /register      → Register new user
  POST   /login         → User login
  GET    /profile       → Get user profile (protected)
  PUT    /profile       → Update profile (protected)
  GET    /all           → Get all users (admin)

PRODUCT ROUTES (/api/products)
  GET    /              → Get all products (with filters)
  GET    /:id           → Get single product
  POST   /              → Create product (admin)
  PUT    /:id           → Update product (admin)
  DELETE /:id           → Delete product (admin)

CART ROUTES (/api/cart)
  GET    /              → Get user's cart (protected)
  POST   /              → Add to cart (protected)
  PUT    /              → Update cart item (protected)
  DELETE /:productId    → Remove from cart (protected)
  DELETE /              → Clear cart (protected)

ORDER ROUTES (/api/orders)
  POST   /              → Create order (protected)
  GET    /myorders      → Get user's orders (protected)
  GET    /all           → Get all orders (admin)
  GET    /:id           → Get order by ID (protected)
  PUT    /:id/pay       → Update to paid (protected)
  PUT    /:id/status    → Update status (admin)
